## [Unreleased]

### Added

- Repository standard: MIT license, contribution and security policy, changelog, and a CI workflow that
  runs the same verification command a contributor runs locally.
- Agentic architecture: `AGENTS.md` as the working contract, an authority map (requirements, journal,
  projection), and a local `team-docs` skill that projects evidence into team-readable documentation
  without creating a second source of truth.
- Drafts, explicitly not requirements: the product thesis, the stack decision, and the first slice.
