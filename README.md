# Gradual Knowledge Discovery (GKD)

**Status: container only.** The product definition — scope, stack, first slice and non-goals — is owned by the agent that opens this repository.

## Boundaries

- **No fork.** Kaddo ([`Kaddo-kdd/kaddo`](https://github.com/Kaddo-kdd/kaddo), MIT) is a reference engine and a dependency candidate, never a vendored base.
- **Primary integration target:** gentle-ai and gentle-shell.
- **Secondary, by construction:** any other agent, through MCP rather than per-agent adapters.
